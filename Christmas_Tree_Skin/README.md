## 🎄Christmas Tree Skin

[![Reachy Mini christmas tree](reachy-mini-skin-christmas.png)]

Give Reachy Mini a bold festive look with this shell customization. This skin combines 3D-printed parts, optional painting, and a magnetic star assembly for a polished final result.

### Steps to make it

1. **3D print the provided files**  
   You can print the parts directly in green filament if you want to reduce the amount of painting.  
   For reference, we printed ours in white.

2. **Paint the parts**  
   If you did not print them in green, you can paint them in green. For reference, we used:
   - **Color:** Pine Green
   - **Finish:** Satin  
   [Reference spray paint](https://www.bricorama.fr/p/peinture-aerosol-vert-pin-satin-400ml/3505390094488)

   Paint the star in **gold**. For reference, we used:
   - **Montana Gold NC-Acrylic spray**  
   [Reference gold paint](https://www.surdiscount.com/fr/montana-cans-gold/39471-bombe-de-peinture-gold-acrylique-goldchrome-m3000-400ml-montana-cans-4048500285943.html)

3. **Insert magnets into the stars**  
   Add magnets inside the stars so they align properly and form a star shape when the antennas touch.

4. **Assemble everything**  
   Once all parts are printed, painted, and fitted with magnets, assemble the skin onto Reachy Mini.
